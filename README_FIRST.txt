PM 6 BEGINNER GUIDED TUTORIAL

This version is designed for a learner who has never completed a full pandas
data-cleaning assignment.

HOW TO START
1. Extract this ZIP file.
2. Keep all files in the same folder.
3. Open PM6_Beginner_Guided_Tutorial.ipynb in Jupyter Notebook.
4. Start at Step 0 and work downward.
5. Read the explanation before running or completing each code cell.
6. Do not manually edit the raw CSV or JSON files.

FILES INCLUDED
- PM6_Beginner_Guided_Tutorial.ipynb
- PM6_Beginner_Tutorial_Guide_and_Rubric.xlsx
- service_requests_raw.csv
- resident_profiles_raw.csv
- service_centres_raw.json

EXPECTED OUTPUTS
The notebook instructs the learner to create an outputs folder containing:
- clean_service_requests.csv
- data_quality_log.csv
- source_specification.csv
